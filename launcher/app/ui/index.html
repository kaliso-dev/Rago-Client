Game engine Experimental

Forge on Java 8, as before, or our own loader: Minecraft on Java 21, without Forge. The Rago loader also runs OptiFine and simple Forge mods from the mods folder (like the account switcher). Mods that need Forge core features are skipped.

Graphics profile

Render distance, clouds, particles, shadows and mipmaps, plus OptiFine's Fast Math, Render Regions and (Competitive) Fast Render. VSync off, unlimited FPS and no background usage reports in all three. You can change anything in game afterwards.

Tuned Java settings

G1 garbage collector tuned for short pauses, memory reserved up front so Java never stops to grow it, no stutter from performance counters on disk, IPv4 straight away for servers.
