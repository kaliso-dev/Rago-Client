# In-Game Account Switcher (bundled)

`InGameAccountSwitcher-Forge-1.8.9-7.1.2.jar` is **In-Game Account Switcher** 7.1.2 for Forge 1.8.9,
by The_Fireplace, The_BrainStone and VidTu, shipped unmodified inside Rago's jar. It handles the
Microsoft sign-in (through its own registered Microsoft application) and stores the accounts; Rago
only adds its own Accounts screen on top and calls the mod's public classes.

- License: GNU LGPL 3.0 (`LICENSE`, which builds on the GNU GPL 3.0 in `COPYING`).
- Source code: https://github.com/The-Fireplace-Minecraft-Mods/In-Game-Account-Switcher
- Releases: https://www.curseforge.com/minecraft/mc-mods/in-game-account-switcher

To use another version, replace the jar here (keep the `InGameAccountSwitcher` prefix in its name).
If a player installs the mod in their own mods folder, that copy is used and the bundled one is skipped.
